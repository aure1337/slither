WORMCASH 🪱

слитерио на рубли — ешь, расти, забирай ₽. Статика: заливается на GitHub Pages без сервера.

Свежие правки

Честный лутДроп = плашка

С убитого червя падает ровно то, что написано у него над головой. Было 34₽ — выпало 34₽ золотыми шариками. Никаких «китов из воздуха».

Своя ставкаВход выбираешь ты

В меню поле «Ставка за жизнь»: вводишь сколько хочешь (от 10₽, не больше баланса) — столько списывается при входе. Кнопка «ИГРАТЬ» всегда показывает актуальную сумму.

Боты поумнелиСмотрят вперёд

Оценивают точку, где будут через ~0.35с, выбирают свободную сторону при побеге, охотятся с перехватом (целятся перед головой жертвы), паникуют и бустят вплотную к угрозе.

Экономика за жизнь

СобытиеЧто происходит с деньгами
Вход в игруСписывается твоя ставка (минимум 10₽)
Съел шарик+2₽ на плашку над головой (1 массы = 1₽)
Убил червяОн рассыпается россыпью золотых крошек на ×1.1 его плашки — съедай быстрее конкурентов
УскорениеТратит массу (≈14/сек), ничего не роняет — катаешься быстрее, но расти не растёшь
«ЗАБРАТЬ»На баланс: собранное + возврат ставки. Жизнь заканчивается
СмертьСтавка и всё собранное сгорают
БанкротКнопка «Подаяние +150₽» вернёт в строй

Как играть

Компьютер

Мышь — направление, ЛКМ / Пробел — ускорение, Esc — пауза (в соло).

Телефон

Веди пальцем по экрану — червяк едет за пальцем. Круглая кнопка «УСКОРЕНИЕ» справа внизу.

С друзьями

Режим «Онлайн» → придумай код комнаты → кинь друзьям ссылку ?room=код или просто код. Падение сети — автоматом боты.

Заливка на GitHub Pages — да, всё так просто

  1. Заведи аккаунт на github.com (если ещё нет) и нажми New repository. Имя любое, например worm-cash, галку «Add README» можно не ставить.
  2. На странице репозитория жми «Add file» → «Upload files» и перетащи всё содержимое папки wormcash: index.html, style.css, папку js/, about.html, README.md. Важно: js/ должна попасть в репозиторий как папка, без неё игра не заведётся.
  3. Жми зелёную кнопку «Commit changes» внизу.
  4. Открой Settings → Pages (в левом меню). В «Build and deployment» выбери Source: Deploy from a branch, ветка main, папка / (root) → Save.
  5. Подожди 1–3 минуты и обнови страницу — сверху появится зелёная плашка с адресом вида https://твой-ник.github.io/worm-cash/. Это и есть твоя игра.

Ссылку можно кидать друзьям — телефон откроет её без установки. Для игры вместе: в меню режим «Онлайн» + одинаковый код комнаты, либо сразу ссылка с ?room=код. Изменить игру позже = загрузить новые файлы в тот же репозиторий (Pages переразвернётся сам). Локально проверить можно двойным кликом по index.html — интернет нужен только для онлайна.

Файл игры — index.html, подробности и тюнинг констант — в README.md.
