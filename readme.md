# Worm Cash — червячки на рубли 🪱💰

Слитерио на рубли: водишь червя, ешь шарики (1 массы = 1₽), давишь чужих —
с убитого падает ровно то, что было у него на плашке. Вход в жизнь — твоя **ставка**:
умрёшь — сгорит, нажмёшь «ЗАБРАТЬ» — вернётся ставка плюс выигрыш.

Чистая статика: **без сервера, без сборки** — заливается на GitHub Pages как есть.

## Что внутри

| Файл | Что это |
|---|---|
| `index.html` | меню (баланс, ник, ставка, скины, комната) + HUD |
| `style.css` | стили, мобильная адаптация |
| `js/util.js` | математика, формат ₽, валидация |
| `js/storage.js` | баланс/ник/скины/ставка в localStorage |
| `js/skins.js` | 12 скинов (3 бесплатных, остальные покупаются за ₽) |
| `js/sfx.js` | звуки на WebAudio, без файлов |
| `js/net.js` | онлайн-комнаты через MQTT (публичные брокеры) |
| `js/game.js` | мир, физика червя, еда, столкновения, рендер |
| `js/bots.js` | боты (уклонение с предсказанием, перехват, кластеры еды) |
| `js/ui.js` | меню, магазин скинов, тосты, итоги жизни |
| `js/main.js` | игровой цикл, ввод, касса/смерть |

## Запуск у себя

Просто открой `index.html` двойным кликом — работает офлайн с ботами.
Для онлайна нужен интернет (библиотека MQTT грузится с CDN).

## Как выложить на GitHub Pages

1. Создай репозиторий на GitHub (например `worm-cash`).
2. Загрузи **все файлы и папку `js/`** в корень репозитория (Add file → Upload files).
3. Settings → Pages → Source: **Deploy from a branch** → ветка `main`, папка **/ (root)** → Save.
4. Через минуту-две игра будет на `https://ТВОЙ_НИК.github.io/worm-cash/`.

## Игра с друзьями

- В меню выбери режим «🌐 Онлайн», в поле «Комната» придумай код (например `vasya`),
  или открой ссылку вида `.../index.html?room=vasya` — комната подхватится из URL.
- Друзья вводят тот же код — вы окажетесь в одном мире и увидите друг друга.
- Без подключения к сети игра автоматически падает в режим ботов.

Технически: каждый клиент публикует своё состояние (~12 Гц) в общий MQTT-топик
комнаты через публичные брокеры (EMQX → Mosquitto → HiveMQ, список в `js/net.js`).
Чужие червяки интерполируются, смерти и деньги приходят событиями.
Это P2P-через-брокер, не выделенный сервер: синхронизация еды упрощённая,
зато ноль затрат и деплой на любую статику.

## Правила экономики

- Ставка за жизнь вводится в меню (минимум 150₽, не больше баланса).
- Еда: обычные шарики 2₽.
- Убил червя — рассыпались золотые шарики на его ₽ с плашки **× 1.1**.
- Ускорение тратит массу (≈14/сек) и ничего не роняет: рывок — чистый минус по росту, компенсации нет.
- «ЗАБРАТЬ» — на баланс идут собранные ₽ **плюс возврат ставки**, жизнь заканчивается.
- Смерть (чужое тело или красная граница) — ставка и собранное сгорают.
- Банкрот? Кнопка «Подаяние +150₽» вернёт в строй.

## Настройка под себя

- Константы мира (скорости, радиус арены, стартовая масса) — `CFG` в начале `js/game.js`.
- Брокеры и пути топиков — `NET` в `js/net.js`.
- Цены и цвета скинов — массив `SKINS` в `js/skins.js`.
- Сложность ботов — `botThink()` в `js/bots.js`.
